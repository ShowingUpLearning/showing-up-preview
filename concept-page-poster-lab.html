2 · True mobile size — 326×183

A 390px phone with the band’s real 32px gutters. This is the legibility gate; there is no automated one, because tools/test-motion-legibility.mjs only scopes .tsx files importing TYPE_V2 and will never see an HTML artboard. Heading 104 renders at 17.7px here, which is the floor the template is designed against.

3 · Native 1920 — craft only

For checking edges and type, not for picking. Each cutout was made for the 4:5 and 1:1 facilitator cards, not for 16:9, and each is clipped differently at its own frame edges: Ben touches only his left (hidden by pinning him to x 0), Hema touches neither, Beth touches both.
